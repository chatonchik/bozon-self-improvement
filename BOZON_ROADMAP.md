- Smarter heartbeat actions (email/calendar/weather triage with quiet hours).

3) Execution quality
- Fewer clarification loops; stronger default assumptions.
- Safe auto-actions with explicit boundaries for external sends.

4) UX style
- Concise answer mode by default in Telegram.
- Optional deep-dive on demand.
