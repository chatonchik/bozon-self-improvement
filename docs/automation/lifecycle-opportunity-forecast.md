# Lifecycle opportunity forecast

Скрипт для цикла self-improvement: превращает RSS-сигналы в вероятностные сценарии и карту возможностей.

## Команда

```bash
node scripts/lifecycle-opportunity-forecast.mjs
```

## Что нового (meta-improvement)

Добавлен **recurrence-aware scoring**:

- учитывает не только количество совпадений по ключевым словам,
- но и повторяемость темы между горизонтом `day/week/month/trending`.

Это снижает влияние разовых хайп-всплесков и повышает вес устойчивых тем.

## Что печатает

- список сценариев с вероятностями;
- драйверы/риски/индикаторы мониторинга;
- opportunity-гипотезы с:
  - уровнем риска,
  - горизонтом,
  - условием инвалидции.

## Зачем

Для цикла полезности Кеше: быстрее переходить от сырого инфошума к конкретным решениям с risk-management, без ложной уверенности.
