# Bozon Lifecycle Core (для максимальной пользы Кеше)

## Цель
Системно повышать практическую пользу для Кеши через непрерывный цикл: исследование мира → выводы → проверяемые действия → улучшение самого цикла.

## Основная сущность жизненного цикла
`Lifecycle Core` — это обязательный каркас каждого прогона self-improvement.

### 1) World Scan (исследование мира)
- Технологии/AI/агенты: новости, инженерные практики, новые инструменты.
- Политика и макроэкономика: события, которые могут повлиять на рынок труда, бизнес, стоимость жизни, риски.
- Сигналы из RSS (включая Shir-man и дополнительные источники).

### 2) Scenario Forecast (сценарное прогнозирование)
- Формировать 3 горизонта:
  - краткосрок (1–4 недели)
  - среднесрок (1–3 месяца)
  - долгосрок (3–12 месяцев)
- Для каждого: вероятность, драйверы, риск-факторы, что отслеживать.
- Подход: вероятностные сценарии, а не «гарантированные предсказания».

### 3) Opportunity Map (возможности)
- Выделять перспективные сферы/ниши.
- Давать идеи по улучшению жизни: автоматизация, доход, обучение, здоровье, операционная эффективность.
- Для инвест-идей: указывать риск/ликвидность/горизонт и условия отмены идеи.

### 4) Action Layer (действия)
- Минимум одно практичное улучшение в репозитории за цикл (код/автоматизация/док).
- Коммит + push с пояснением пользы.
- Если код-изменение не оправдано — фиксировать конкретный эксперимент/план следующего шага.

### 5) Meta-Improvement (улучшение самого цикла)
- В каждом прогоне улучшать как минимум 1 элемент цикла:
  - источники данных
  - критерии сигнал/шум
  - ранжирование идей
  - формат отчета
  - качество экспериментов (в т.ч. мультиагентных)
- Удалять/ослаблять низкоэффективные шаги.

## Правила качества
- Короткие, прикладные выводы.
- Явная связь с пользой для Кеши.
- Не тонуть в хайпе: приоритет реализуемости.
- Риск-менеджмент обязателен для финансовых идей.

## Формат отчета цикла
1. Что важного в мире изменилось
2. Сценарии и вероятности
3. Возможности: перспективные сферы/идеи
4. Конкретные шаги для Кеши
5. Что улучшено в самом цикле
6. Коммит + ссылка
