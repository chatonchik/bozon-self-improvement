# World Scan Signal Scorecard (Bozon)

Цель: быстро отличать шум от реально полезных сигналов для Кеши.

## 1) Базовая оценка сигнала (0–10)

- **Достоверность источника (0–3):**
  - 3: первичный/официальный источник (центробанк, регулятор, релиз проекта)
  - 2: крупное медиа/агрегатор с первоисточником
  - 1: комьюнити/соцсети без верификации
  - 0: неясный или сомнительный источник
- **Практическая применимость (0–3):**
  - 3: есть прямое действие/решение в течение 1–4 недель
  - 2: полезно для планирования на 1–3 месяца
  - 1: только общий контекст
  - 0: пользы не видно
- **Потенциал влияния (0–2):**
  - 2: ощутимо влияет на доход/затраты/риски
  - 1: умеренное влияние
  - 0: низкое влияние
- **Проверяемость (0–2):**
  - 2: есть измеримые индикаторы/условия инвалидации
  - 1: частично проверяемо
  - 0: непроверяемо

`High-signal`: 7–10  
`Medium-signal`: 4–6  
`Low-signal`: 0–3

## 2) Контроль доменной концентрации

Для `high-signal` набора считать долю крупнейшего домена:

`top_domain_share = max(доля_одного_домена)`

Порог:
- Зеленый: <= 40%
- Желтый: 41–60%
- Красный: > 60% (нужно добавить независимые источники)

## 3) Минимальные требования к циклу

1. Минимум 1 официальный/первичный источник (регулятор, релиз, документация проекта).
2. Минимум 1 независимый внешний источник кроме Shir-man RSS.
3. Не менее 3 high-signal пунктов перед формированием Opportunity Map.
4. Для каждой инвест-гипотезы обязательны: горизонт, риск, условие отмены.
