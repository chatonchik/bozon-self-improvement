4. **Policy/geopolitics по AI** остаются фактором системного риска (фрагментация доступа, compliance-ограничения, зависимость от регионов/провайдеров).

## 2) Сценарии + вероятности

### Краткосрок (1–4 недели)
- **Сценарий:** усиление hardening в агентных workflow.
- **Вероятность:** 0.85
- **Драйверы:** высокий объём сигналов по security + повторяемость по всем горизонтам RSS.
- **Риски:** часть сигналов приходит из шумных соц-источников.
- **Индикаторы мониторинга:** новые кейсы prompt injection, обновления sandbox/policy enforcement, security advisories.
- **Уверенность:** средняя/высокая.

### Среднесрок (1–3 месяца)
- **Сценарий:** нормализация мульти-модельных каскадов (cheap-first, escalate-on-failure).
- **Вероятность:** 0.85
- **Драйверы:** плотный поток релизов + давление на unit-economics.
- **Риски:** ухудшение качества при агрессивной экономии.
- **Индикаторы:** cost per successful task, P95 time-to-completion, авто-success rate.
- **Уверенность:** средняя/высокая.

### Среднесрок (1–3 месяца)
- **Сценарий:** умеренно-осторожный режим риска на фоне макро-неопределенности.
- **Вероятность:** 0.80
- **Драйверы:** сигналы по занятости/инфляции + регулярные монетарные релизы ФРС.
- **Риски:** локальные отскоки могут давать ложный «risk-on».
- **Индикаторы:** FOMC-релизы, инфляция, рынок труда, кредитные спрэды.
- **Уверенность:** средняя/высокая.

### Долгосрок (3–12 месяцев)
- **Сценарий:** нарастание региональной фрагментации AI-policy и инфраструктурных ограничений.
- **Вероятность:** 0.75
- **Драйверы:** policy-сигналы по defense/compliance и поставочным ограничениям.
- **Риски:** переоценка политических заголовков без реальных продуктовых последствий.
- **Индикаторы:** ToS/geo-ограничения у провайдеров, export-control апдейты, compliance требования.
- **Уверенность:** средняя/высокая.

## 3) Opportunity map (практические идеи)

1. **Усиление reliability/security слоя агента**
   - Гипотеза: расширение набора preflight-checks и инъекционных тестов снижает ручные откаты.
   - Риск: низкий.
   - Горизонт: 1–4 недели.
   - Invalidation: если за 2 недели нет снижения доли rollback/ручных отмен.

2. **Каскад моделей по экономике выполнения**
   - Гипотеза: cheap-first routing даёт 15–25% экономии на задачу без просадки качества.
   - Риск: средний.
   - Горизонт: 1–3 месяца.
   - Invalidation: падение success rate >5 п.п. на контрольной выборке.

3. **Защитная аллокация капитала/ликвидности (risk-managed)**
   - Гипотеза: частичное сохранение ликвидной подушки + диверсификация по инструментам/валютам снижает просадку в policy-волатильности.
   - Риск: средний.
   - Горизонт: 1–3 месяца.
   - Invalidation: устойчивое улучшение макроданных (>=2 последовательных релиза) + снижение волатильности кредитных спредов.
